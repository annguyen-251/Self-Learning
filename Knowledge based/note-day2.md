# Day 2 — Math & Input

## What I learned
- Math works directly with variables: distance / speed
- Division always returns a float (decimal), even if the numbers divide evenly
- input("prompt") pauses the program, shows the prompt text, and waits for the user to type something
- Whatever the user types comes back as a string — even if they type a number

## Note
- input() always returns text (string) — if you need it as a number, you have to convert it (more on this next lesson)
